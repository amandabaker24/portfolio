# portfolio

Here is a portfolio of what I do, if you are interested.

Amanda Baker’s portfolio, built with Next.js, React, and TypeScript. Includes an interactive project showcase and case studies for QuantumMed, Menoviq, and Nori.

## Local development

```sh
npm ci
npm run dev
```

Open http://localhost:3000.

## Production

```sh
npm run build
npm start
```

## Nori screens

The recreated Nori interface assets live in `public/nori`. To regenerate them:

```sh
node scripts/build-nori-screens.mjs
```
